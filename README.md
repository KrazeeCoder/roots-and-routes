
  # Visually Appealing Website

  This is a code bundle for Visually Appealing Website. The original project is available at https://www.figma.com/design/Irg44BzpzLCG8xZL5qRejk/Visually-Appealing-Website.

  ## Running the code

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.

  ## Environment variables

  Add these to your local environment file (`.env` or `.env.local`):

  - `VITE_SUPABASE_URL`
  - `VITE_SUPABASE_PUBLISHABLE_KEY`
  - `VITE_CLOUDINARY_CLOUD_NAME` (used for Cloudinary fetch URL optimization; if missing, original image URLs are used)
